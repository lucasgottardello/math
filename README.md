SPANISH:
Funciones de representación de la multiplicación, potenciación y tetración (llamada 'potencia siguiente') en C++;
F(x) = multiplicación(int a,b) => función recursiva que devuelve el resultado de axb utilizando la suma básica.
F(x) = potencia(int a,b) => función recursiva que devuelve el resultado de a^b utilizando la función 'multiplicación()' previa.
F(x) = potencia_siguiente(int a,b) => función recursiva que devuelve el resultado de (a^a, 'b' veces) utilizando las funciones 'potencia()' y 'multiplicación()' previas.
El resto de las funciones son sólamente para el análisis de datos.

ENGLISH:
Functions representing multiplication, potentiation and tetration (called 'next power') in C++;
F(x) = multiplication(int a,b) => recursive function that returns the result of axb using basic addition.
F(x) = power(int a,b) => recursive function that returns the result of a^b using the previous 'multiplication()' function.
F(x) = next_power(int a,b) => recursive function that returns the result of (a^a, 'b' times) using the previous 'power()' and 'multiplication()' functions.
The rest of the functions are only for data analysis.
